# Footer — independent spec

- Keep a meaningful, responsive nonempty footer for sites. Share header logo, name, nav configuration, theme and i18n; never create a second brand store.
- Public website: brand + short truthful purpose, real Quick Links, appropriate department/services links only if routes or anchors exist, copyright with dynamic year; translations must be complete. No invented addresses, socials, policies, support email, testimonials, certifications, delivery promises.
- Internal dashboard: compact but useful footer/status metadata, not a giant marketing footer.
- Use Vuetify layout components and semantic links; no blank columns or dead `href="#"` placeholders.
- Verify visible at desktop/mobile, in both locales and themes, without padding that wastes half the page.
